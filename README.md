# Aegis Bot

Aegis est un bot discord développer pour gérer mon server discord.
Ses taches sont les suivantes :

- Gestion des rôles dans le server
- Gestion des nouveaux arrivants
- Mise en place d'un système de logs des commandes

- Mise en places de divers systèmes drôles

- Mise en place d'un système de gestion de la musique (via Spotify)
